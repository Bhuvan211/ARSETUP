## 📌 About The Project

**ARSETUP** is a Unity-based Augmented Reality project created to explore AR development, interactive digital content, and real-world environment integration.

The project is part of my journey in **Game Development & Design**, focusing on developing practical skills in Unity, C#, 3D environments, and immersive technologies.

---

## 🎯 Objectives

- 📱 Learn Augmented Reality development with Unity
- 🎮 Develop interactive AR experiences
- 🌍 Understand real-world environment interaction
- 🧩 Learn AR scene and project configuration
- 💻 Improve C# programming skills
- 🚀 Explore mobile AR development
- 🕶️ Build a foundation for future AR/VR projects
